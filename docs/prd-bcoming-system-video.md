# PRD: Bcoming System Video

## Purpose
Create a short animated explainer that shows how Bcoming helps a user move from inner chaos to a meaningful next step.

The first founder video proves that life dots can connect. This second video explains the system that helps the user connect their own dots and move forward whether they feel lost, have an idea, or are already building a business.

## Story
1. Chaos: the user feels overwhelmed by thoughts, doubts, ideas, and pressure.
2. Adaptive entry: Bcoming makes clear that it works for three starting points: lost, idea, and already building.
3. Atlas: the chaos becomes dots, clusters, and patterns.
4. Mentors: the system reads those patterns and turns insight into direction.
5. Project: direction becomes a concrete plan, roadmap, and next action.
6. Creators: the user builds with people, network, and impact.
7. Together: the final image lands on Bcoming as a social network for conscious creators.

## Design Direction
- Use the supplied concept frames as the visual foundation, but darken and simplify them so embedded text becomes atmosphere rather than the main explanation.
- Keep the spoken/captioned story extremely simple: one clear idea per scene.
- Add cinematic motion through slow zooms, pan, light sweeps, particles, dot connections, and glow pulses.
- Match the Bcoming cosmic visual language: dark background, glass surfaces, violet, cyan, gold, emerald, soft glow.
- Keep the animation lightweight with React and Framer Motion for the prototype.
- Add an interactive path selector in the adaptive entry scene so users can see that Bcoming adapts to their current stage.

## Duration
- Target: 40 to 45 seconds for the interactive website prototype so users have time to read.
- Later Remotion/ad export can be edited down to 20 to 30 seconds with voiceover-led pacing.
- Avoid long copy. Use short scene labels and motion to explain the system.
- Primary message: "Bcoming meets you where you are, then helps you find the next meaningful step."
- Final message: "Bcoming is a place for conscious creators to connect, collaborate, and create what matters."

## Placement
- First prototype gets a standalone preview route.
- Add the video to the public website after a short problem/framing section while testing the message.
- Place the "We help you to WIN" feature explanation directly under the video so visitors see the emotional story first, then the system promise.
- Later placement recommendation: after `Start my map`, before the first Atlas quest, so the user understands why Atlas, Chats, Projects, and Creators are connected.

## Acceptance Criteria
- Shows the full system loop from chaos to Atlas to mentors to project to creators.
- Shows that Bcoming can help people who feel lost, have an idea, or are already running a business.
- Uses the supplied scene images as cinematic backgrounds in the correct emotional sequence.
- Feels like one transformation: lost to discovery to clarity to guidance to creation to collective impact.
- Reduces cognitive load by limiting each scene to one main message.
- Works responsively on mobile and desktop.
- Includes a centered replay button when the sequence ends so users can watch it again.
- Does not overlap bottom navigation when embedded in the app.
- Production build passes.
